# GrilleÉval

Évaluer les tests et faire le bilan des compétences.

Aucune donnée d’élève n’est envoyée : chaque test est enregistré dans un fichier .json sur l’appareil de l’enseignant.

Statistiques d’utilisation anonymes (GoatCounter, sans cookie ni script extérieur) : seulement l’ouverture de l’application et le nom de quelques actions (test enregistré, bilan affiché ou enregistré, PDF exporté), plus, au plus une fois par semaine et par mois, un signal « appareil actif » sans identifiant pour estimer le nombre d’utilisateurs ; jamais de noms d’élèves, de titres de tests ni de notes.
