# GrilleÉval

Évaluer un test et regrouper plusieurs tests dans un bilan des compétences.

L’application fonctionne entièrement dans le navigateur. Aucune donnée d’élève n’est envoyée : chaque test est enregistré dans un fichier .json sur l’appareil de l’enseignant, avec une copie de secours dans le navigateur.
