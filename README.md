# GrilleÉval

Évaluer les tests et faire le bilan des compétences.

Aucune donnée d’élève n’est envoyée : chaque test est enregistré dans un fichier .json sur l’appareil de l’enseignant.

Statistiques d’utilisation anonymes (GoatCounter, sans cookie) : seulement l’ouverture de l’application et le nom de quelques actions, jamais de noms d’élèves, de titres de tests ni de notes.
